# Alexandra Nozhenko — Personal Portfolio

A responsive personal portfolio featuring a professional statement, skills, and three academic project summaries.

## Publish on GitHub Pages

1. Create a **public** GitHub repository named `portfolio`.
2. Upload `index.html` and `README.md` to the repository root and commit them to the `main` branch.
3. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**. Select `main` and `/ (root)`, then save.
4. After deployment, open `https://YOUR-USERNAME.github.io/portfolio/` and test the navigation and content.
5. Submit the public repository URL and the live GitHub Pages URL.

## Before submitting

- Confirm each project description accurately reflects work you personally completed.
- Add links to project repositories or demos if you have them. No unverified or placeholder project links are included.
- Verify the GitHub Pages website is publicly accessible.
